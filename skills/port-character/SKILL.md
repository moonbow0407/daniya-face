# 用捏脸模板做一个角色

写给任何编码 agent（不依赖特定模型或工具）。需要能读写文件、运行命令；能开浏览器看页面更好。
本手册随引擎模板仓库一起分发：命令、目录、工作台都是模板自带的。

**好不好玩取决于两件事**：每个动作有没有一眼能看出来的表情，以及拉脸时有没有穿模。
人设、性格描述不是这里的重点——表情直接按动作来配。

## 规则

1. 只改 `src/characters/<id>/` 和 `site.json`（`npm run port` 会自动改 `src/characters/index.js`）。引擎缺功能就告诉用户，不要自己改引擎。
2. 模型里的名字（材质、骨骼、表情）只用 `SURVEY.md`、`model.js` 和工作台里出现过的，不要编。
3. **写表情前先看表情**：在工作台"全部表情"里把缩略图看一遍。同名表情在不同模型里观感可能完全不同。
4. 每次改完运行 `npm run port -- check <id>`：`✗` 必须修到 0；`!` 里关于区分度和穿模的提醒也要处理，处理不了就告诉用户原因。

## 流程

| 步骤 | 谁 | 产出 |
| --- | --- | --- |
| 0 建项目 | 你 + 用户 | 用户自己的仓库、`site.json` |
| 1 导入 | 脚本 | 角色目录、`model.js`、`SURVEY.md` |
| 2 看表情 | 你（工作台） | 一张"能用的表情"清单 |
| 3 配表情 | 你 → 用户确认 | `expressions.js`、`model.js` 的 `morphs` |
| 4 配色 | 脚本取色 → 你选 | `theme.js` |
| 5 检查 | 脚本 | `check` 0 错误 |
| 6 验收 | 你 + 用户 | `hairRest.json`；不穿模、位置对、表情对 |
| 7 上线 | 脚本 + 用户 | 设为默认角色、部署 |

### 0. 建项目（已经在模板项目里就跳过）

当前目录有 `site.json` 和 `scripts/port/` 就是模板项目，直接到第 1 步。否则从模板建用户自己的仓库：
GitHub 上 **Use this template**，或 `gh repo create <新仓库名> --template <模板仓库> --public --clone`（模板地址问用户，默认 `moonbow0407/daniya-face`）；本地已有模板就 `git clone <模板目录> <新目录>` 再把 `origin` 改成用户的仓库。然后 `npm install`。

改 `site.json`（问用户要值，不要沿用模板作者的）：`links` 里"源码"改成用户的仓库；`cloudflare.pagesProject` 改成用户的项目名；`cloudflare.analyticsToken` 没有就**清空**。

素材（模型、立绘）由用户下载好放进来：模之屋等站点需要用户自己登录下载，不要尝试绕过登录。

### 1. 导入

需要：角色中文名、英文 id（小写，如 `phoebe`）、模型 `.pmx`（放在 `public/models/<目录>/`，贴图在同目录的子目录里）。缺什么问用户。

```bash
npm run port -- new <id> --model public/models/<目录>/<模型>.pmx --name <中文名>
```

把输出和 `SURVEY.md` 里"需要人确认"的条目转告用户。贴图找不到（含大小写不一致）会直接报出来，先修好再往下走。

### 2. 看表情（工作台）

```bash
npm run dev
```

打开 `http://localhost:5173/?char=<id>&studio`，展开左下角工作台的 **全部表情**：模型里每个表情一张缩略图，悬停在模型上预览。
- 标了语义名的是已经映射进 `model.js` 的；半透明的是开到 1 也几乎看不出的（嘴型常这样），不要拿它们当主表情
- 眼部贴片（`><`、`X_X`、漩涡眼、爱心眼）和漫画符号（💢、汗滴、竖线）最明显，`SURVEY.md` 的"按材质分组"里能找到它们
- 不能看页面时：控制台 `window.__studio.openGallery()`，再读 `window.__studio.morphs`（`score` 是明显变色的像素占比，< 0.0015 基本看不出）

记下每个表情实际长什么样（比如"`なごみ` 是一条黑条""`星目` 很淡""`照れ` 只是更浓的脸红"），挑出能用的。

### 3. 配表情

按动作配，每个动作一个**招牌**表情 + 一个**变体**，动作之间要一眼能分出来。先列一张表给用户确认：

| 动作 | 招牌 | 变体 |
| --- | --- | --- |
| 戳 | 例：`><` 眼一闪，随后眯眼笑 | 连戳 3 下以上：吃惊、瞳孔缩小 |
| 单手拉 | 例：被拉一侧眯眼 + 皱眉 | 约 30%：半眼嫌弃 + 💢 |
| 双手拉 | 例：`X_X` | 无语竖线 + 半眼 |
| 捧 | 例：脸红 → 享受时爱心眼 | 揉晕：漩涡眼 |

然后：
1. 用到但没映射的表情，加进 `model.js` 的 `morphs`（语义名自己起，英文驼峰，后面注释写实际观感）
2. 写 `src/characters/<id>/expressions.js`（模板已按动作分好段；信号说明在文件开头）：
   - 招牌 / 变体用 `p.roll`（每次动作开始掷一次，`p.roll >= 0.7` 走变体）；戳的变体还可以看 `p.combo`（连戳次数）
   - 招牌表情给足 0.6~1；眼部表情乘 `p.open`；保留文件开头的物理反应
   - 拉脸变体也可以写成 `personality.eggs`（只写 `morphs`；模型有 UV 符号贴片时才加 `symbol`）
   - 顶点表情做的漫画符号（💢、竖线）原样又大又艳：在 `model.js` 加 `vertexSymbols`，给每个符号定位置 `at`、大小 `scale`（0.3 左右）、填充色 `tint`，引擎会按达妮娅汗滴的画风重新上色（见 `docs/PORTING.md` 3.1）
3. `personality.js` 里 `behavior` 调节奏（捧多久害羞 / 享受、揉多久晕），`actions` 决定开放哪些动作
4. 看过渡，不只看定格：有的表情开到一半很难看（比如眯眼笑半开时眼珠从睫毛下露出来）。遇到就把它加进 `model.js` 的 `instantMorphs`，表情表里只给 0 / 1，中间用眨眼衔接
5. 工作台 **演示** 里逐个看：上面一排选"招牌 / 变体"可以固定看某一种，"连戳""揉"也有按钮。看不出差别就加大或换表情

### 4. 配色

```bash
npm run port -- palette <id> --image public/<立绘或模型贴图>
npm run port -- theme <id> --colors '#主色,#辅色,#点缀色'
```

主色通常是发色，辅色是瞳色或服装主色，点缀色是饰品色。

### 5. 检查

```bash
npm run port -- check <id>
```

0 个 `✗` 才算过。`!` 里的"没有变体""X 和 Y 的表情几乎一样""最强的表情只有 0.xx"说明区分度不够，回第 3 步。

### 6. 验收

1. **烘焙头发**：`npm run dev` 下打开 `http://localhost:5173/?char=<id>&bake`，等加载完会自动写入 `src/characters/<id>/hairRest.json`（控制台显示"已写入"）。
2. **前发避让**：工作台 **材质** 里逐个取消勾选头发材质，找出挡在脸颊前的那几层（常叫 `Bangs` / `前髪`，不一定叫 hair），确认它们就是 `model.js` 的 `materials.hairOnCheek`。写错了拉脸时脸颊会从发丝里穿出来。
3. **拉到最大不穿模**：单手、双手拉到最大，看脸颊边缘。还穿就调小 `hairAvoid.slack`（发丝更早让开），细节见 `docs/PORTING.md` 第 5 节。
4. **位置**：戳、拉落在脸颊肉上。偏了调 `calibration`：上下偏调 `dy`，内外偏调 `sx`，每次 0.01~0.02。
5. 自己看页面时：浏览器把页面放到后台会暂停动画帧，加载会停住；可以在控制台用 `__face.step(60)` 手动推进帧。截图前确认模型已经画出来（不是只有描边）。

### 7. 上线

- 设为默认角色：`npm run port -- default <id>`；不要示例角色了：`npm run port -- remove daniya --yes`
- 部署：`./deploy.ps1`（预览）或 `./deploy.ps1 -Prod`（正式）。第一次会打开浏览器登录 Cloudflare，请用户自己登录
- 素材不进 git（`.gitignore` 已排除），提醒用户遵守模型作者的使用条款

## 完成时汇报

每个动作的招牌 / 变体用了哪些表情（附实际观感）、`hairOnCheek` 是哪几层、配色三个颜色、`check` 结果、哪些还没在浏览器里验收。提交、推送、部署只在用户要求时做。
